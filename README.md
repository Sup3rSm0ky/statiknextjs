# CatatDuit — Personal Finance Tracker

Personal finance tracker dengan multi-account support, dibangun pake Next.js 14 + Supabase.

## 📚 Panduan Lengkap (BACA URUT)

Lo baru pertama kali pake Next.js? **Ikutin urutan ini:**

1. **`docs/01-SETUP.md`** — Install Node.js, code editor, dan tools yang dibutuhkan
2. **`docs/02-SUPABASE.md`** — Bikin akun Supabase dan setup database
3. **`docs/03-LOCAL-RUN.md`** — Jalanin project di laptop lo
4. **`docs/04-EMAIL-AUTH.md`** — Setup email reset password
5. **`docs/05-DEPLOY.md`** — Publish ke internet pake Vercel
6. **`docs/06-CUSTOM.md`** — Tips customize lebih lanjut

## ⚡ Quick Reference

- **Stack**: Next.js 14 + TypeScript + Tailwind + Supabase
- **Total biaya**: Rp 0 (free tier semua)
- **Estimasi waktu setup**: 1-2 jam (kalau pertama kali)
- **Akun yang harus dibikin**: GitHub, Supabase, Vercel (semua gratis)
